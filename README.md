# Travel Transit App

A minimal travel and transportation mobile app concept built with React Native + Expo.

## Features
- Trip planning dashboard
- Route and transport selection cards
- Nearby food and dining suggestions
- Profile and travel preferences
- Modern mobile UI

## Run locally

1. Install dependencies:
   npm install

2. Start the app:
   npm start

3. Open the app in Expo Go or run:
   npm run android
   npm run ios

## Project structure
- `App.js` – main app shell and tab navigation
- `src/components` – reusable UI pieces
- `src/screens` – home, routes, food, and profile screens
- `src/data` – mock data for the app
